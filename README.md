# ラクマート発注レシピ v3

## 今回の変更
- 発注レシピは「オーダー用」表示にだけ表示（前版仕様を維持）。
- レシピ未登録商品は、既存の `発注URL1〜3 / サイズ / カラー` から初回たたき台を生成。
- 発注URLが1件：自動で「構成品1件」としてたたき台を生成（未保存）。
- 発注URLが2件以上：「全部発注する / 代替仕入先 / 手動で作る」を選んでたたき台を生成。
- たたき台は自動保存しない。内容確認後に「保存」で初めてDBへ保存。
- 規格軸は任意。規格値だけで保存可能。
- UIは「規格値」を先、「規格軸（任意）」を後に変更。
- Playwright想定：まず規格値で探索し、同値候補が複数ある場合だけ規格軸を補助キーとして使用する前提。
- 保存後再読込RPC修正を維持。

## 適用
1. 前回の再読込修正SQLをまだ実行していない場合は、Supabase SQL Editorで `supabase/rakumart_order_recipe_reload_fix.sql` を実行してください。実行済みならDB変更は不要です。
2. `src/App.tsx` と `src/App.css` を差し替え。
3. ビルド・デプロイ。

`supabase/rakumart_order_recipes.sql` は新規環境用の全体SQLとして同梱しています。既存環境では今回新しいテーブル変更はありません。

## 初回作成例
- URL1だけ: 商品本体 + URL1 + サイズ/カラーを「規格値」として候補化。
- URL1/URL2が本体+袋: 「全部発注する」を選択 → 2構成品に分離。
- URL1/URL3が同商品の別ショップ: 「代替仕入先」を選択 → 1構成品の仕入先候補としてまとめる。
